03 / PUT IT TO WORK

A small model.
A real starting point.

Define a depot, add customers, and solve a capacitated routing root relaxation. No instance file required.

  • Model directly with Python objects
  • Inspect bounds, duals, and route columns
  • Export results as a dictionary or JSON

Python returns an LP relaxation; routes may have fractional values. Use the CLI or Rust for integer tree search.

Explore the Python API ↗
first_route.pyPYTHON
from pybaldes import Customer, Instance

# Depot first, then customers with unit demand.
instance = Instance("first-route", capacity=2, customers=[
    Customer(0, 0),
    Customer(1, 0, demand=1),
    Customer(0, 1, demand=1),
])

result = instance.solve_root(
    problem_type="cvrp",
    capacity_cuts=True,
)
print(result.status, result.lp)
for route in result.routes:
    print(route.value, route.nodes)
Working with files or building a Rust application?

Solve a Solomon instance

Run from the checkout after installing the CLI.

baldes vrptw instances/Solomon/R101.txt \
  --customers 10 --rank1 --tree --time 60
