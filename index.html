Vehicle routing,

BALDES 2.0 is a complete Rust rewrite of the bucket-graph labeling engine. It prices resource-constrained shortest paths, separates limited-memory rank-one cuts, fixes arcs and enumerates elementary routes, and drives a stabilized column-and-cut generation root. The core uses only the Rust standard library.

01 — Engine

What's in 2.0

A purpose-built pricing engine for vehicle routing. Bucket graphs organize dominance, bidirectional labeling meets in the middle, and rank-one cuts tighten the relaxation, all inside a column-and-cut generation loop.

🗂️
Bucket Graph Labeling
Labels grouped in buckets by vertex and resource interval, processed in strongly connected component order, with jump arcs and dominance against preceding buckets.
↔️
Bidirectional Pricing
Forward and backward labeling with a half-way point that moves toward the lighter direction, and symmetric joins when the graph allows a single direction.
✂️
Limited-Memory Rank-One Cuts
One- and three-row separation, local-search and tuple-based four- and five-row separation, and packed cut state in pricing and enumeration labels.
🧭
Fixing & Enumeration
Reduced-cost fixing removes bucket arcs that cannot lead to an improving route; when the gap is small, every elementary route is enumerated and priced by inspection.
📈
Stabilized Column Generation
Dual-price smoothing with misprice handling, a Clp restricted master, cut rounds with basic-cut removal, and artificial-column penalties.
🦀
Safe, Dependency-Light Rust
The solver core is plain Rust on the standard library. Clp is an optional feature, linked through its C interface only for the master LP.

cargo build --release --features clp

03 — Algorithms

Staged pricing strategy

Cheap heuristic phases find improving columns fast; the exact phase proves there are none left; fixing and enumeration then shrink what remains to be priced.

01
Heuristic labeling
Few labels per bucket and resource-and-cost dominance only. Phases move toward the exact one when they stop finding negative columns.
02
Exact labeling
Full dominance on resources, NG memory and cut state, with jump arcs. No negative column left means the master LP is optimal.
03
Cut separation
Rank-one cuts are separated on the fractional master solution, rank by rank, until the bound tails off.
04
Fixing & enumeration
With an incumbent, bucket arcs are fixed by reduced cost and, when few routes remain, all elementary routes are enumerated and priced by inspection.
04 — Design

Built for research & production

Every architectural decision balances algorithmic correctness, memory efficiency, and reproducibility over convenience magic.

01
Algorithm-first design
The bucket graph mirrors the mathematical structure of the pricing problem; no abstraction leaks the model.
02
Memory-conscious
Packed cut words in every label, arena-held label ancestry and bounded buckets keep peak memory predictable.
03
Deterministic
Fixed tie-breaking and seeded randomness: the same instance gives the same trajectory, iteration by iteration.
04
Rust all the way down
Memory safety without a garbage collector; the only foreign code is the optional LP backend.
