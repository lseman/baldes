Checks if element 'a' precedes element 'b' in the given strongly connected components (SCCs).

This function takes a vector of SCCs and two elements 'a' and 'b' as input. It searches for 'a' and 'b' in the SCCs and determines if 'a' precedes 'b' in the SCC list.
