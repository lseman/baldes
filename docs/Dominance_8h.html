Batch dominance check: test B new_labels against the same set of existing labels.

Uses SIMD to compare multiple new_labels' costs/resources/visited against each existing label in parallel. Returns true if ANY new_label is dominated by an existing label.

Batch size is encoded in the template parameter BATCH_SIZE (typically 4 or 8).
