Unified solve and routing methods

Python
solve(problem, *, rows=(), time_limit=120.0, max_iterations=100000,
      stabilize=True, stabilization_max_tree_depth=10000,
      bound_mode="numerical", pricing_options=None, **options
) -> Union[RootResult, NetworkResult]

problem accepts an Instance, a path, a PricingNetwork, an array of PricingNetwork objects, or a NetworkProblem. A .json path reads a network model; other paths read routing input. rows= supplies shared rows when passing a scalar network or array; a complete NetworkProblem already owns its rows. One network and a one-element array normalize to the same model and defaults.

Model-specific keywords are documented in routing options and network options. Routing input returns a RootResult; network input returns a NetworkResult. Routing constraint type is inferred by default; problem_type="vrptw" or "cvrp" overrides it.

Network model and snapshot methods

Fresh network inputs use the same solve operation above. Its **options include tree, network scheduling/branching, enumeration, mapped variables, proximal stabilization and synchronization controls; see the complete network option tables. NetworkNode.solve resumes its retained model and accepts the corresponding snapshot options.
