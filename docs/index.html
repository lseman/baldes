Operation Rust CLI Python
Routing root relaxation master::routing::solve / Instance::solve solve INSTANCE solve(instance) / instance.solve()

Low-level RCSP pricing pricing::Solver Used within solves Solver
Original master variables without pricing master::model::solve_master Rust-only static-variable registration Rust-only static-variable registration
Complete enumerated node MIP Model/routing snapshot interfaces --enumerated-mip with supported registration Network snapshot / model options

Shared-master registrations require clp; optional HiGHS/Gurobi backend and integer-copy features are documented beside their interfaces. Different registrations can install different cut, branch and witness hooks while sharing construction, CG, pricing coordination and tree dispatch.

Root Optimal means the configured LP relaxation converged. Tree Optimal closes the configured integer-domain gap within its tolerances and proof policy. A restricted-column incumbent alone is not a lower-bound proof. Read concepts and results before comparing bounds across models or interfaces.
