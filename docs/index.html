The routing tree currently models one pricing network. A network is a separate routing subproblem, such as a vehicle type or depot. Forward and backward labeling within one graph do not create multiple networks. Ryan–Foster branching works with one network. Packing-set assignment rows are supported, but useful fractional assignment branching requires multiple networks; see Branching.

Root Optimal means the LP relaxation converged. Tree Optimal means the integer routing gap closed within the configured tolerances. A feasible restricted-column solution supplies an incumbent; its objective alone does not prove a lower bound for the full routing problem.

Keeping the guides current

When changing behavior, update the owning guide and its linked source/tests. For BALDES options, keep OPTION_TABLE support metadata and the reference table in sync. Check documented commands and links rather than treating a historical test count as a permanent guarantee.
