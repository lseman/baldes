Solver components

  • Bucket-graph labeling: resource and NG preparation, bucket grids, strongly connected component ordering, jump arcs, preceding-bucket dominance, bidirectional search with a moving half-way point, and symmetric joins.
  • Const-generic scalar resource dimensions, defaulting to two, with fixed-array labels, feasibility, dominance, enumeration, and replay. See scalar resources.
  • Staged pricing with the native heuristic phase schedule.
  • Reduced-cost fixing on bucket arcs and elementary route enumeration with inspection pricing at the root and descendant nodes.
  • Limited-memory rank-one (subset-row) cuts: 1- and 3-row separation, local-search and tuple-based 4- and 5-row separation, cut memory, and limited- and full-memory cut state in pricing and enumeration labels.
  • Dual-price smoothing, and a Clp-backed restricted master with cut rounds, basic-cut removal and artificial-column penalties; optional native IPM master solves.
  • Rounded capacity and Kohl 2-path cuts, with time-window feasibility checks; strong k-path and route-load knapsack cuts integrated with pricing, enumeration, and inherited master rows.
  • Solomon VRPTW and CVRPLIB CVRP input, HGS heuristic, initial-column seeding, and root solving.
  • Dynamic NG strengthening from master cycles at configurable separator priority.

The core solver uses only the Rust standard library. The clp feature links COIN-OR Clp through its C interface for the restricted master. The optional highs feature adds a HiGHS LP backend and integer solving.

Additional cut configuration

Strong k-path and route-load knapsack cuts are available in the Rust root API through with_kpath_cuts and with_knapsack_cuts. The latter takes original integer resource rows; KnapsackCutConfig::with_resource_indices maps original resource IDs to solver coordinates. Load-dependent costs and that mapping pass through pricing, enumeration, and inherited master rows.
