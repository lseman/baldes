02 / MAKE IT RUN

Your next route
starts here.

Build the routing CLI, try a Solomon instance, then explore the model one piece at a time.

Build requirements & configuration ↗

The Clp build needs a C++14 compiler. HiGHS is optional. Python exposes root relaxations and pricing; use Rust or the CLI for the tree.

● ● ●GETTING STARTED / TERMINAL
git clone --recurse-submodules https://github.com/lseman/baldes.git
cd baldes
cargo build --release --features clp

# A small routing tree with rank-one cuts
./target/release/baldes vrptw instances/R101.txt \
  --customers 10 --rank1 --tree --time 60
Use Python for a root relaxation
python -m pip install .
import pybaldes

result = pybaldes.solve_root(
    "instances/R101.txt", customers=10,
    capacity_cuts=True, rank_one_cuts=True,
)
print(result.status, result.lp)
Add HiGHS for enumerated node MIP

Install a HiGHS shared library with 32-bit HighsInt, then build both backends.

cargo build --release --features clp,highs
./target/release/baldes vrptw instances/R101.txt \
  --customers 10 --tree --enumerated-mip --time 60
